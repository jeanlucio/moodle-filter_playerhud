The **PlayerHUD Filter** is a required companion plugin for the [PlayerHUD Block](https://github.com/jeanlucio/moodle-block_playerhud).
It enables the insertion of collectible item drops, trade offers, and the compact HUD widget directly inside Moodle
course content using shortcodes.

This filter allows teachers to embed interactive drop elements within pages, labels, books, and other
HTML-supported activities, integrating seamlessly with the PlayerHUD gamification system.
