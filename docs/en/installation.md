# 🛠️ Installation

1. Ensure the **PlayerHUD Block** is installed first — the filter depends on the block and will
   not install without it.

   👉 <https://github.com/jeanlucio/moodle-block_playerhud>
2. Download the `.zip` file or clone this repository.
3. Extract the folder into your Moodle `filter/` directory.
4. Rename the folder to `playerhud` (if necessary).
   Final path:
   `your-moodle/filter/playerhud/`
5. Visit **Site administration > Notifications** to complete installation.

The filter enables itself automatically once installed — no extra step needed. If shortcodes
show up as literal text on your site, check that it was not manually disabled in
**Site administration > Plugins > Filters > Manage filters**.
